## Corrections backed by source inspection

- The Angular HTTP client expects an adapter in front of the gRPC service. A complete adapter implementation is not present in this repository.
- The C# worker consumes files with admission/charge data, not a direct gRPC connection to the patient gateway.
- The console development environment uses synthetic fixtures, including pipeline status.
- Infrastructure declaration tests and per-service CI do not establish end-to-end runtime validation or compliance certification.
- FIFO deduplication is not an unlimited, system-wide guarantee against duplicate billing.

## Verification scope

On September 19, the local policy suite passed **71 checks** with Python 3.12. Relative documentation links and the SVG cover were validated; the cover was also inspected in a browser. These checks do not exercise the distributed services.

Existing GitHub workflow history was inspected: the latest available Java, Kotlin, Go, C#, Angular and policy runs were successful, at different commits because the workflows have path filters. No claim is made that all services were rerun locally during this documentation change. Policy checks are run separately and their result is recorded in the handoff.
